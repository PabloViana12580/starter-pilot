# Owner images

Put the business's own photos and logos here (JPEG, PNG, or WebP, any size).
Then run:

    python manage.py optimize_images

It writes web-sized WebP copies to `static/img/` (orientation fixed, location
and camera metadata removed) and lists them in `static/img/CREDITS.md`.
